# 2026-11-13 工作日志

## 漫画阅读平台 (Manga Reader Platform)

### 完成内容
- 构建了漫画上传/阅读平台，包含以下功能：
  1. 用户注册/登录（localStorage 存储用户数据，密码哈希）
  2. 漫画上传：标题、作者、简介、封面、标签、多章节（每章多页图片）
  3. 编辑功能：只有漫画发布者（owner）可以编辑自己的作品
  4. 阅读器：全屏翻页阅读，支持键盘左右箭头导航、ESC 关闭
  5. 弹幕系统：阅读时可以发送弹幕，弹幕以滚动动画显示在页面上方，可开关
  6. 好友系统：搜索用户、发送好友请求、接受请求、好友列表

### 技术决策
- 云服务激活时资源池紧张，用户未确认激活，回退到本地实现
- 使用 localStorage 存储结构化数据（用户、漫画元数据、弹幕、好友关系）
- 使用 IndexedDB 存储图片 Blob（封面和漫画页面图片）
- 总文件数压缩为 2 个：index.html（含全部 CSS）+ app.js（全部逻辑）

### 文件结构
- index.html — 单页应用入口，内联所有 CSS 样式
- app.js — 完整应用逻辑（Store 层 + App 对象）
